# Zala Sharing

Offline phone <-> TV sharing. Both devices join the same Hotspot (no internet needed).
Works on Android phones and Android TV / Google TV (TCL).

## Get the APK (no Android Studio needed)
1. Create a free GitHub account, make a new repository, upload everything in this folder
   (keep the `.github` folder).
2. Open the repository -> Actions tab -> "Build Zala Sharing APK" -> wait about 5 minutes.
3. Open the finished run -> Artifacts -> download "ZalaSharing-APK" (ZIP) -> unzip -> ZalaSharing.apk

## Build with Android Studio
Open this folder, let it sync (Gradle 8.7, JDK 17), then Build > Build APK(s).
